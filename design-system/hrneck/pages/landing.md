# Landing Page Overrides

> **PROJECT:** HRNECK
> **Page Type:** Landing / Marketing

> Rules in this file **override** the Master file. Only deviations are documented here.

---

## Page-Specific Rules

### Layout Overrides

- First viewport: brand (hero-level), one headline, one supporting sentence, one CTA group.
- Max width ~72rem; generous white space (Minimalism / Swiss).
- No cards in the hero; no floating badges or promo chips on media.

### Spacing Overrides

- Content density: standard / marketing (Master density 5), not dashboard-dense.

### Color Overrides

- Default theme is **light**. Dark is optional via theme toggle.
- Primary navy + green accent on `#F8FAFC`.

### Component Overrides

- Header CTAs use default (min 44px) tap targets, not compact `sm`.
